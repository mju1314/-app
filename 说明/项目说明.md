# ExpenseTracker 项目说明

## 1. 项目定位

这是一个面向个人长期自用的 Android 离线记账 App，核心目标不是做复杂财务系统，而是把下面几件事做好：

- 记账录入足够快
- 明细查看和筛选足够直接
- 统计回看足够清楚
- 数据支持导出、备份、恢复

当前第一版已经完成核心闭环，可以直接在手机上真实使用。

## 2. 技术栈

- Kotlin
- Jetpack Compose
- Navigation Compose
- Room
- DataStore Preferences
- Hilt
- Gradle Kotlin DSL

## 3. 当前已完成的主要功能

### 首页
- 今日支出
- 本月支出
- 最近记录列表

### 记一笔
- 新增支出
- 分类选择
- 支付方式选择
- 备注
- 记账时间可编辑，默认是当前手机时间

### 明细
- 按时间倒序查看记录
- 按关键词搜索备注 / 分类 / 支付方式
- 按分类筛选
- 按时间范围筛选：全部、最近 7 天、本月
- 支持进入记录详情

### 记录详情
- 编辑金额、分类、支付方式、备注
- 编辑记账时间
- 删除记录

### 统计
- 查看指定月份总支出
- 分类占比
- Top 分类
- 日均支出
- 最近 7 天 / 30 天趋势
- 支持回看历史月份
- 支持直接输入年份并选择月份跳转

### 设置
- 默认货币设置
- 默认仅显示当前默认货币，点击后再展开选项
- CSV 导出
- 本地备份
- 本地恢复
- 清空记录

当前项目里的 [gradle.properties](C:\Users\15218\Desktop\app\gradle.properties) 配置了：

```properties
org.gradle.java.home=D:\\develop\\JDK\\jdk17
```

这是一台当前电脑的本地 JDK 路径。以后换电脑后，这一行大概率需要修改，或者直接删掉并改用新电脑自己的 JDK 配置。

## 7. 构建与安装

### Debug 包

构建：

```powershell
.\gradlew.bat assembleDebug
```

安装到已连接手机：

```powershell
.\gradlew.bat installDebug
```

### Release 包

构建：

```powershell
.\gradlew.bat assembleRelease
```

生成位置通常在：

`app\build\outputs\apk\release\app-release.apk`

## 8. Release 签名说明

当前项目已经加上了 `release` 签名配置，配置位置在：

- [app/build.gradle.kts](C:\Users\15218\Desktop\app\app\build.gradle.kts)

签名信息通过根目录下的 `keystore.properties` 读取。

### 重要

以下文件 **不要上传 GitHub**，但你自己必须单独保存：

- `keystore.properties`
- `*.jks`
- `*.keystore`
- `*.p12`

也就是说，真正长期最重要的是：

1. 你的签名文件，例如：
   `C:\Users\15218\.keystore\expense-tracker-release.jks`
2. 你的签名密码
3. `keystore.properties` 中的配置内容

如果以后换电脑继续发 release 版本，必须继续使用同一个 `jks`，否则无法覆盖升级已经安装在手机上的 release 版。

## 10. 换电脑继续开发时怎么做

### 需要拷走的内容

建议你至少保存下面这些：

1. 整个项目目录

2. 你的 release 签名文件 `.jks`

   目录：C:\Users\15218\.keystore\expense-tracker-release.jks

3. `keystore.properties` 内容

4. 如果手机里已有真实数据，建议在 App 内做一次本地备份，把备份 zip 也单独保存

### 到新电脑后的操作顺序

1. 安装 JDK 17
2. 安装 Android Studio 和 Android SDK 34
3. 把整个项目拷到新电脑
4. 把 `.jks` 放到你新电脑的安全目录
5. 重新创建根目录下的 `keystore.properties`
6. 视情况修改 `gradle.properties` 里的 `org.gradle.java.home`
7. 执行：

```powershell
.\gradlew.bat assembleDebug
```

或者：

```powershell
.\gradlew.bat assembleRelease
```

### 如果 release 安装升级失败

优先检查：
- 是否还在使用同一个 `.jks`
- `storePassword` / `keyPassword` 是否正确
- `applicationId` 是否还是 `com.example.expensetracker`
